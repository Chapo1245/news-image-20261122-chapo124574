**Sum up 22 November's world news in one image.** A 1024×1024 newspaper
front page: **35 stories across 7 regions**, 3 lead stories, 10 illustrated
scene cards, a dotted world map with pins, a stat strip, 22 briefs, and a
DATE CHECK listing 9 items that are *not* 22 November news.

## How to run

```sh
python3 main.py        # writes entry.png (1024x1024 PNG, <= 1 MiB)
```

Deterministic: two runs produce a byte-identical file. No network access.
Requires Pillow and the DejaVu fonts (standard on most Linux systems).
