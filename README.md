One image summing up the world's news of **Sunday 22 November 2026** — a
front page drawn fresh from that day's reporting: Iran strikes US assets in
Bahrain as the Gulf war spreads, Hong Kong votes for 723 Election Committee
seats, COP31 deadlocks into overtime, the EU and Indonesia sign a decade
trade deal, Russia's barrage hits Lviv station, and a cartel kingpin is
seized in Sinaloa — plus 20 more stories from every region, a world map of
where it happened, and the day's numbers.

## How it works

`main.py` (Python 3.13, standard library only) copies the pre-rendered
`entry.png` (1024×1024, 163,468 bytes) to `$MAKEFUN_OUTPUT_DIR` (or
`/output`). The image is a fixed artifact, so two runs always write
byte-identical output, with no network access.

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
